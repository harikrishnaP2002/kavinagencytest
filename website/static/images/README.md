# Currency Note Images

This folder contains Indian currency note images for the denomination calculator.

## Required Images

Please add the following images with these exact filenames:

1. `500-rupee-note.png` or `500-rupee-note.jpg` - ₹500 Indian currency note image ✅ (Sample provided)
2. `200-rupee-note.png` or `200-rupee-note.jpg` - ₹200 Indian currency note image
3. `100-rupee-note.png` or `100-rupee-note.jpg` - ₹100 Indian currency note image
4. `50-rupee-note.png` or `50-rupee-note.jpg` - ₹50 Indian currency note image
5. `20-rupee-note.png` or `20-rupee-note.jpg` - ₹20 Indian currency note image
6. `10-rupee-note.png` or `10-rupee-note.jpg` - ₹10 Indian currency note image
7. `5-rupee-note.png` or `5-rupee-note.jpg` - ₹5 Indian currency note image

## Image Specifications

- **Format**: PNG or JPG (both supported)
- **Recommended Size**: 140x70 pixels (2:1 aspect ratio)
- **Display Dimensions**: Width: 70px, Height: 35px (as displayed in calculator)
- **Aspect Ratio**: 2:1 (width:height) for best display

## Sample Image

A sample ₹500 Indian currency note image has been provided as `500-rupee-note.png`. Use this as a reference for the style and quality of other denomination images.

## Note

If images are not found, the calculator will display a simple gray placeholder with the amount text.
